## トーンガイド

| NG | OK |
|----|-----|
| 煽り・不安を煽る（「手遅れになる前に」） | 共感から入る（「こんな経験ありませんか」） |
| 過度な権威主張（「唯一」「公式」「最強」） | 具体的なシーン（「認知症の診断後」） |
| 効果を保証する表現 | 行動コストを下げる表現（「押すだけ」「3タップで」） |

**免責の原則**：センター情報の正確性を保証する表現は使わない。  
「実際の情報は各自治体公式サイトでご確認ください」の趣旨を投稿に添える。

## プラットフォーム別方針

### X（旧Twitter）

- 各投稿は140字前後でシーン提示 → アプリURL
- ハッシュタグ候補：`#介護` `#地域包括支援センター` `#認知症` `#在宅介護` `#ケアマネ` `#高齢者`
- 推奨投稿時間：平日 8:00〜9:00 / 21:00〜22:00（介護層が見やすい時間）

### アプリ紹介文・ストア説明文

- 1〜2文の短い紹介文と、100〜200字の詳細説明文の2バージョンを用意する
- 「無料」「個人制作」であることを明示する

### SEO提案

- ターゲットキーワード：`地域包括支援センター 検索` / `介護相談 電話` / `{都市名} 地域包括`
- `index.html` の `<title>` / `<meta description>` / JSON-LD の変更案はAgent-04の確認を通す
